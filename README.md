# Calculator

A simple web-based calculator built with HTML and CSS.

## Files

- `index.html` - Calculator UI and button click behavior.
- `style.css` - Styling for the calculator layout and appearance.

## Features

- Number buttons: 0-9
- Basic arithmetic operations: addition, subtraction, multiplication, division
- Percent button
- Parentheses input
- Decimal point support
- Clear button
- Equals button to calculate results

## Usage

1. Open `index.html` in a web browser.
2. Click the buttons to build a mathematical expression.
3. Press `=` to evaluate the expression.
4. Use `C` to clear the input.

## Notes

- The calculator uses the browser's built-in `eval()` function for expression evaluation.
- Ensure valid expressions are entered before pressing `=` to avoid errors.
